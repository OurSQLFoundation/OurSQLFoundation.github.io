The Reference Manual is MySQL's canonical documentation, maintained by Oracle and published per major/minor version (currently covering the 8.0, 8.4 LTS, and 9.x Innovation release lines side by side). It spans installation and upgrade instructions, the full SQL statement and function reference, storage engine internals (InnoDB, MyISAM, and others), replication and group replication setup, the security and privilege system, performance schema and monitoring, and the C/connector APIs.

Each version's manual is also downloadable as HTML, PDF, EPUB, and man pages for offline use, and the online version is kept current as patch releases ship.
