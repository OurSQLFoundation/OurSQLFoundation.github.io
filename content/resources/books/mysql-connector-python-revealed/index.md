*MySQL Connector/Python Revealed: SQL and NoSQL Data Storage Using MySQL for Python Programmers* covers MySQL's official Python driver, version 8.0. It shows how to install the connector, run basic and advanced SQL queries, and trap errors and troubleshoot problems, and then how to use the X DevAPI — the API under all of MySQL's language connectors — to work with MySQL as a document store.

The author, Jesper Wisborg Krogh, was a member of the Oracle MySQL Support team, and also wrote [MySQL 8 Query Performance Tuning](/resources/books/mysql-8-query-performance-tuning/) and [MySQL Concurrency](/resources/books/mysql-concurrency/). Published by Apress in 2018.
