*MariaDB Cookbook* is a collection of more than 95 short recipes for working with MariaDB: getting started and configuring it, migrating tables from MyISAM to Aria, using the CONNECT storage engine to read and write CSV and XML files and other data sources, MariaDB's performance features and optimizer improvements, and its built-in NoSQL features — dynamic columns, where rows can hold different sets of columns, and virtual columns.

At the time of writing, the author, Daniel Bartholomew, worked for MariaDB managing releases, documentation, and the infrastructure that keeps the project running. Published by Packt in 2014; it is often recommended as a more approachable start than larger MariaDB references.
