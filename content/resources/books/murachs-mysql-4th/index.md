*Murach's MySQL* teaches SQL on MySQL in five sections: the basics of retrieving, adding, updating, and deleting data with MySQL Workbench; more advanced queries with summaries, subqueries, data types, and functions; database design and implementation, including views; stored procedures, functions, triggers, and events; and an introduction to database administration — security, backup and restore on a local server, and the same tasks on a MySQL database hosted on AWS.

Like other Murach books, it uses paired pages, with syntax and examples on the right and explanations on the left, and ends each chapter with exercises. The fourth edition, published by Mike Murach & Associates in 2023, is updated to MySQL 8.0.33.
