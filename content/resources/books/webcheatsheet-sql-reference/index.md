WebCheatSheet's SQL Reference is a free written guide to the core of SQL: query clauses, joins, grouping, aggregate functions, and data modification. It can supplement beginner SQL learning.

The examples are engine-general rather than specific to MySQL, so check dialect differences against the MySQL documentation when you apply them.
