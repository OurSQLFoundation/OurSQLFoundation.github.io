*Database Design and Modeling with PostgreSQL and MySQL* starts with the differences between SQL and NoSQL databases and hands-on setup of both engines, then works through core design concepts — keys, constraints, transactions, and concurrency — and on to query optimization, views, stored procedures, and triggers, ending with best practices and where database design is heading. Examples are shown for both PostgreSQL and MySQL, and the code is on GitHub.

The authors are [Alkin Tezuysal](/resources/member-directory/people/alkin-tezuysal/), a long-time MySQL community figure, and Ibrar Ahmed, a PostgreSQL database architect. Published by Packt in 2024.
