*MySQL Troubleshooting* works from simple problems to complex ones: it starts with issues that can be reproduced on a single connection in isolation, then moves on to concurrency, server options, the server environment, and replication. Along the way it covers tools such as the slow query log, InnoDB monitors, and the Performance Schema.

The author, Sveta Smirnova, wrote it while a principal technical support engineer in the Bugs Verification Group of the MySQL Support Group at Oracle. Published by O'Reilly in 2012.
