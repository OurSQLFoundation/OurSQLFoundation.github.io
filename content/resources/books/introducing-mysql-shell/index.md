*Introducing MySQL Shell: Administration Made Easy with Python* introduces MySQL Shell, the client that replaced the classic `mysql` command line for many tasks. It works in SQL, Python, and JavaScript modes, and the book shows how to use it interactively, how to work with the X DevAPI and the Document Store, and how to script administration — including the AdminAPI used to build and manage InnoDB Cluster.

The author, Charles Bell, was a member of the Oracle MySQL development team and led the MySQL Utilities team. Published by Apress in 2019, at about 500 pages.
