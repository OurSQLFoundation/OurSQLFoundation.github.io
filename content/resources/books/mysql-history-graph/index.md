MySQL History Graph traces the family tree of MySQL and its ecosystem of forks and derivatives — from the original MySQL releases through Percona Server, MariaDB, Drizzle, MySQL Cluster, InfiniDB, TiDB, VillageSQL, GreatSQL, RonDB, and more — as a single diagram showing which version branched from which. The graphs (PNG and SVG) are generated from GraphViz DOT files, which are open to edits and pull requests.
