*SQL Performance Explained* explains how database indexes work and how to write queries that use them — the WHERE clause, joins, sorting and grouping, partial results, and inserts, updates, and deletes — in under 200 pages. Rather than covering one database, it shows the same concepts and execution plans across MySQL, PostgreSQL, Oracle, and SQL Server.

The full content is free online as [Use The Index, Luke](https://use-the-index-luke.com/), which the author keeps current; its MySQL examples have been tested on versions from 5.5 to 9.7. The book is sold directly by the author as a paperback or PDF.
