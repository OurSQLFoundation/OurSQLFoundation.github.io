DB Service on Samsung Cloud Platform, run by Samsung SDS, provisions and manages relational databases — MySQL, MariaDB, PostgreSQL, EDB Postgres Advanced Server, SQL Server, Tibero, and Vertica — on virtual machines inside a customer's VPC. Creation is automated from a web console, and the service handles backup and recovery, minor-version patches, parameter changes, audit logging, and monitoring.

For high availability it uses an active-standby pair kept in sync by software-level synchronous replication, and MySQL and MariaDB can add read replicas for read scaling or disaster recovery. Backups are stored in object storage and can be restored to a specific point in time. Billing is hourly without a contract or a fixed monthly fee with one.
