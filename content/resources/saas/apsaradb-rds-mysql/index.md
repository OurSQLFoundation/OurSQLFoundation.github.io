ApsaraDB RDS for MySQL runs a managed MySQL instance on Alibaba Cloud, handling provisioning, patching, backups, and failover, with read-only replicas for scaling reads and a dedicated-cluster edition aimed at higher-throughput production workloads. It supports MySQL 5.5 through 8.0, and an instance can be switched between the subscription (pay-upfront, fixed-term) and pay-as-you-go (hourly, metered) billing methods without migrating data.

Alibaba Cloud publishes a SOC 2 Type II report and a PCI DSS attestation through its compliance program, alongside TDE encryption at rest, SSL in transit, and IP whitelisting/VPC-based network isolation for the RDS service.
