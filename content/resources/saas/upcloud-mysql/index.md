UpCloud's Managed Database for MySQL runs MySQL Community Edition on a master/replica architecture: single-node plans are available, while 2- and 3-node clusters add automated failover, with the management system promoting a replica if it detects a failure on the master. Clusters are provisioned and configured through UpCloud's API or control panel, with settings such as admin credentials and `innodb_lock_wait_timeout` exposed directly.

Backups run automatically, are encrypted, and are stored off-site independently of the database cluster, with retention tiers that scale from a few days on entry-level plans up to 31 days on extended-retention tiers (at extra cost). Billing is hourly per node. UpCloud, headquartered in Helsinki, Finland, states that its infrastructure is ISO/IEC 27001 certified and GDPR compliant.
