OVHcloud's Public Cloud Databases for MySQL runs on one or more Public Cloud instances that OVHcloud manages on the customer's behalf, currently supporting MySQL 8.0 and 8.4 under the standard MySQL Community (GPL) license, with no separate license fee. Clusters are created from the Public Cloud control panel by choosing a MySQL version and a plan, and the plan can be upgraded after creation.

Three tiers are offered: an Essential/Discovery single-node tier for development, a Business/Production 2-node tier, and an Enterprise/Advanced 3-node tier for high availability. The service is billed pay-as-you-go, with compute, storage, and automated off-site backups metered separately. OVHcloud also publishes a guide for connecting a Managed Kubernetes cluster to a Public Cloud MySQL database, and a migration guide for importing an existing MySQL 5.7/8.0 database with GTID replication enabled.
