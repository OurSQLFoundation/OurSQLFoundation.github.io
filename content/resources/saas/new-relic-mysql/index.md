New Relic's MySQL monitoring integration sends MySQL and MariaDB metrics to the New Relic observability platform: server status such as slow queries per second, connected threads, and InnoDB buffer pool metrics, plus query-level data on slow queries, individual query executions, wait events, blocking sessions, and query execution plans. Optional metric groups cover replication and backups.

The quickstart installs a MySQL Overview dashboard and four alerts. It requires MySQL 5.7 or later (8.0+ recommended) or MariaDB 10.x. New Relic uses usage-based pricing, and every account includes 100 GB of data ingest per month free.
