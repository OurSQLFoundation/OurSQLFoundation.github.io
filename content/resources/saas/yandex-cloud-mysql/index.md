Yandex Managed Service for MySQL deploys ready-to-use MySQL clusters of up to seven hosts in Yandex Cloud, on standard, memory-optimized, or CPU-optimized hosts with network SSD storage. Yandex Cloud handles virtual machine deployment, OS and DBMS installation and updates, backups, replication setup, and monitoring, while the customer controls data access.

Clusters support read replicas and custom replication topologies, and point-in-time recovery restores a database to any moment in the last seven days. Data is stored encrypted, and cluster health and resource use can be watched in the console or exported through the API. The service supports MySQL 5.7 and 8.0.
