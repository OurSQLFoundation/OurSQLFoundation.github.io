Data Replication Service (DRS) provides real-time migration, real-time synchronization, real-time disaster recovery, data subscription, and workload replay across more than 20 relational and non-relational databases. For MySQL, sources can be self-managed MySQL 5.5 to 8.0, MySQL on other clouds, or Huawei Cloud RDS for MySQL, and destinations include RDS for MySQL, FlexusRDS for MySQL, DDM, and TaurusDB, using full or full-plus-incremental migration. The destination must be the same version as the source or later.

Other features include migration without taking services offline, data comparison between source and destination, two-way synchronization for cross-region active-active disaster recovery, and replay of captured production workloads.
