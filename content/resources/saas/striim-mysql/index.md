Striim's MySQL connector captures every insert, update, and delete from MySQL using non-intrusive change data capture and streams the changes to cloud data warehouses, data lakes, or real-time applications with sub-second latency. MySQL is supported both as a source and as a target, and Striim lists integrations with Amazon RDS for MySQL, Amazon Aurora MySQL, Azure Database for MySQL, and Google Cloud SQL for MySQL.

Striim is available as Striim Cloud, a fully managed SaaS, or as Striim Platform for on-premises or self-managed cloud deployments.
