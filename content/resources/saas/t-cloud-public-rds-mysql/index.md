T Cloud Public, the public cloud from Deutsche Telekom previously known as Open Telekom Cloud, offers MySQL through its Relational Database Service. Instances run as a single node or as a high-availability primary/standby pair with automatic or manual switchover, can add read replicas, and are backed up automatically or on demand. RDS for MySQL supports manual minor-version upgrades, and MySQL 8.4 is available in the EU-DE and EU-NL regions alongside 8.0.

Billing follows the hourly price of the chosen virtual machine flavor, with backup storage charged separately. Unlike most hyperscalers, T Cloud Public includes e-mail and phone support in the price, and it positions its German data centers as a GDPR-compliant home for European workloads.
