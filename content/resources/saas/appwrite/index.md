Appwrite is an open-source (BSD-3-Clause) backend platform that bundles authentication, databases, storage, serverless functions, messaging, and realtime into one project, deployable self-hosted via Docker or as a managed cloud service.

In September 2026, Appwrite added native MySQL databases: a managed MySQL 8.4 instance (8.0 is also supported) provisioned inside an Appwrite project with its own hostname, credentials, and TLS enabled by default, plus IP allowlists enforced before authentication. It supports online resizing across eight compute tiers, storage autoscaling, and scheduled/manual backups with point-in-time recovery. Native MySQL and PostgreSQL databases are available today across every Appwrite Cloud region (Frankfurt, New York, San Francisco, Singapore, Sydney, and Toronto).

Appwrite Cloud has a free tier plus paid Pro and Enterprise plans billed on a subscription basis.
