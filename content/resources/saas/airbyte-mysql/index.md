The Airbyte MySQL connector extracts data from MySQL and loads it into more than 50 destinations, such as Snowflake, BigQuery, Databricks, or Postgres, on scheduled syncs. It can run on Airbyte Cloud, on the open-source Airbyte platform, or in a hybrid setup where the data plane runs in your own environment and only configuration and job metadata go to Airbyte's control plane.

Airbyte Cloud offers a free 14-day trial with no credit card required. The open-source platform is on [GitHub](https://github.com/airbytehq/airbyte).
