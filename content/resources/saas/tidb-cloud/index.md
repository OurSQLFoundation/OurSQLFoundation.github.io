TiDB Cloud runs PingCAP's distributed SQL database as a managed service, handling provisioning, scaling, backups, and upgrades across AWS, Google Cloud, and Azure. Because TiDB speaks the MySQL wire protocol and supports most MySQL 5.7/8.0 syntax, existing MySQL clients, drivers, and tooling connect with little to no code change while gaining horizontal scale-out and TiFlash's built-in columnar engine for real-time analytics alongside transactional workloads.

It's offered in three tiers: a Starter plan with a free monthly quota of storage and request units, a capacity-based Essential plan, and a node-based Dedicated plan billed hourly for production clusters that need dedicated resources and stronger isolation.
