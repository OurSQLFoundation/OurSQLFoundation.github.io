Redgate Monitor brings SQL Server, PostgreSQL, Oracle, MySQL, and MongoDB into one monitoring view, with performance diagnostics, alerting, and estate-wide reporting. It supports MySQL 8.0 and later, on self-managed servers or on Amazon RDS, Amazon Aurora, Azure Flexible Server, and Google Cloud SQL.

It is licensed per monitored node — each node of a multi-node cluster such as Aurora needs its own license — and comes with a 14-day free trial. Redgate's roots are in SQL Server tooling, and it also makes Schema Compare for MySQL.
