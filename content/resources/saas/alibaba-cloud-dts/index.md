Data Transmission Service (DTS) migrates data between relational, NoSQL, and OLAP data stores, for both homogeneous migrations such as MySQL to MySQL and heterogeneous ones such as Oracle to MySQL. It moves data from on-premises databases or ECS-hosted databases into ApsaraDB RDS (or back), and between RDS instances, with virtually no downtime, by capturing and parsing the source database's change logs in real time. For MySQL sources, DDL changes are synchronized as well.

DTS also offers real-time subscription to RDS change data and continuous replication. Schema migration and full data migration are free; incremental migration is pay-as-you-go, and synchronization tasks are available pay-as-you-go or by subscription.
