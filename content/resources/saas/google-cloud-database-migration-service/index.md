Database Migration Service supports one-time and continuous migrations from source databases into Cloud SQL. For MySQL, sources can be self-managed MySQL (on premises or on any cloud VM you control), Amazon RDS, Amazon Aurora, Azure Database for MySQL, or another Cloud SQL for MySQL instance, across versions from MySQL 5.5 to 9.7 depending on the source. The destination is always Cloud SQL for MySQL, on the same version as the source or one version higher.

Google notes the service isn't compatible with MariaDB.
