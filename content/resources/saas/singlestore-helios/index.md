SingleStore Helios is the managed cloud version of SingleStore, a distributed SQL database built for mixed transactional and analytical workloads, available on the major public clouds. It separates storage and compute and scales out elastically, and it is wire-compatible with MySQL, so applications can connect with MySQL drivers and tools.

SingleStore documents a transition path from MySQL, starting with SingleStore Flow, a no-code tool for moving data, and notes that it intentionally does not support every MySQL feature, so schemas may need adjusting. Schema changes run online, even under production load. A free shared tier is available.
