RDS for MySQL is Huawei Cloud's fully managed relational database service for MySQL. It uses a hot-standby architecture with enhanced semi-synchronous replication to the standby, where a failover takes a few seconds and an RTO of under 60 seconds is achievable, and it stores three copies of data on cloud disks for redundancy.

Instances support restoring a database or table to any point in time, read replicas with one-click rebuild of the standby or replicas when replication lags or breaks, and a DBA Assistant for fault diagnosis, capacity analysis, and slow SQL analysis. MySQL 8.4 is supported, and a kernel minor version can be chosen when buying an instance.
