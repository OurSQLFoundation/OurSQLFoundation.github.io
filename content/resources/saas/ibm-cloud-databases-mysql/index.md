IBM Cloud Databases for MySQL is a fully managed MySQL service integrated into IBM Cloud. Deployments span three data centers in an IBM Cloud multi-zone region for a 99.99% SLA, and IBM manages backups (including point-in-time recovery), read replicas, logging, monitoring, and scaling. Disk, RAM, and vCPUs scale independently, with auto-scaling, and customers can bring their own encryption key for data at rest.

MySQL 8.4 is the preferred version for new deployments. IBM lists the service as HIPAA- and GDPR-ready and compliant with PCI DSS, SOC 2 Type 2, ISO 27001, ISO 27017, and ISO 27018. Billing is hourly, with Isolated Compute and Shared Compute hosting models.
