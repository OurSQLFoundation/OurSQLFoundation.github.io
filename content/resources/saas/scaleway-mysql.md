Scaleway offers MySQL (alongside PostgreSQL) as a managed Database-as-a-Service, provisioned from either shared-vCPU "Cost Optimized" instances or dedicated-vCPU "Production Optimized" instances on newer hardware, with hourly billing, automated backups, and Multi-AZ availability on read replicas.

The service runs out of Scaleway's own European data centers — Paris, Amsterdam, Warsaw, and Milan — each deployed as a 3-availability-zone region, and is managed through the same console and API as the rest of Scaleway's cloud platform.
