Aiven for MySQL runs on AWS, Google Cloud, Azure, and other clouds, with automated backups, monitoring, and connection pooling handled by Aiven. It also includes AI Insights, Aiven's AI database optimizer: built on the EverSQL engine Aiven acquired in 2023, it watches the service for slow queries and suggests indexes and query rewrites, using query metadata rather than the data itself. A standalone SQL query optimizer in the Aiven console accepts MySQL queries too.
