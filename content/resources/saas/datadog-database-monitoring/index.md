Datadog Database Monitoring (DBM) gives visibility into databases through the Datadog Agent, which collects data from the database and sends it to Datadog. For MySQL it provides historical query metrics for normalized queries (latency, execution time, rows examined), query samples showing what is running at a given time, explain plans, and host-level and custom metrics.

Datadog documents MySQL 5.6, 5.7, 8.0, and 9 on self-hosted servers, Amazon RDS, Amazon Aurora, Google Cloud SQL, and Azure, with a separate setup for MariaDB. DBM also correlates distributed traces with query metrics and explain plans. Datadog offers a 14-day free trial of its full product suite.
