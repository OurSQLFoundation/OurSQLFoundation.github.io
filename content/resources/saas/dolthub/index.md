DoltHub is the git-style hosting service built by the team behind Dolt, the version-controlled SQL database. It hosts Dolt database repositories the way GitHub hosts Git repositories: public repositories are free to host and browse, with diffs, commit history, branches, and pull requests for both data and schema changes shown in the web UI.

Private repositories require a DoltHub Pro subscription — the first 100 MB of private data is free, billed from $5/month above that. The company separately offers Hosted Dolt, a fully managed `dolt sql-server` instance for teams that want a running database rather than just a hosted repository. Because Dolt speaks the MySQL wire protocol, databases on either offering connect with standard MySQL clients and drivers.
