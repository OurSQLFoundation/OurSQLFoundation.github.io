Stackhero runs managed open source services, and its MySQL offering puts each database on dedicated, isolated infrastructure with fast CPUs and NVMe/SSD disks. A MySQL server starts in about two minutes, and Stackhero handles automatic daily backups and keeps the server up to date, with new MySQL releases applied in one click.

It adds no soft limits such as caps on concurrent connections. Services are billed per hour on a single monthly invoice, with servers in the US and Europe. Stackhero is a European company, GDPR-compliant and ISO 27001 certified, and also offers MariaDB.
