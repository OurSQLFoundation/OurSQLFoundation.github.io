Database Observability is part of SolarWinds Observability SaaS and covers MySQL alongside PostgreSQL, SQL Server, MongoDB, and Redis. An agent on the database host collects detailed information about each instance and sends it to SolarWinds, which tracks query performance, resource use, processes, and the server metrics that affect performance.

It discovers MySQL databases running locally and also monitors Amazon RDS and Aurora. Because it is delivered as SaaS, new features arrive as SolarWinds deploys them. A free trial is available.
