The Estuary MySQL connector captures every insert, update, and delete in real time using change data capture, reading from MySQL binary logs for low-latency streaming with exactly-once delivery into Estuary collections, and backfills existing data for a complete initial sync. It works with self-hosted MySQL, Amazon RDS, Amazon Aurora, Google Cloud SQL, and Azure Database for MySQL.

Connections can use SSH or SSL, schema discovery and time zones are handled automatically, and data is encrypted in transit and at rest. Estuary runs in its public cloud, in a private deployment, or in your own cloud account.
