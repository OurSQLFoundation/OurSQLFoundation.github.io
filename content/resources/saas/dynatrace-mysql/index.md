Dynatrace monitors MySQL as part of its full-stack observability platform. With OneAgent installed on the host, or on Kubernetes and OpenShift where MySQL runs as a workload, the MySQL extension collects database metrics, while OneAgent's code-level tracing shows which application calls and queries hit the database, including from Node.js `mysql` and `mysql2` clients.

The extension covers MySQL 5.7; for MySQL 8.x Dynatrace offers a separate remote monitoring extension. Data feeds Dynatrace's dashboards, alerting, and AI-driven root-cause analysis. Dynatrace is sold as SaaS with a free trial.
