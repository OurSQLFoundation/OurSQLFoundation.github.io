TaurusDB is Huawei Cloud's enterprise-grade, cloud-native database, fully compatible with MySQL. It separates storage from compute and keeps three copies of data across multiple availability zones, for zero data loss (RPO = 0) and automated failover with an RTO under 10 seconds. A single instance scales up to 128 TB of capacity.

It is offered as a serverless edition billed per hour that scales compute with fluctuating workloads, and as single-node and cluster instances on yearly plans. Recent additions include lock-free schema changes, vector search, and an MCP server for using the database from AI clients.
