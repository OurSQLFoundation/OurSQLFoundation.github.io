NHN Cloud, the cloud business of the South Korean internet company NHN, offers RDS for MySQL: virtual machines with MySQL installed and managed, sized to the specification and volume the customer picks. A high-availability option keeps the database available when a failure occurs, with instances placed across availability zones.

Backups run automatically or on demand, can be restored to a new instance, and can be exported to the customer's object storage. Events on each instance can be subscribed to and delivered by e-mail or SMS. RDS for MySQL requires NHN Cloud's Compute & Network services to be enabled first.
