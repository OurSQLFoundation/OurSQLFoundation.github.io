Azure Database Migration Service (DMS) migrates external MySQL instances, including on-premises servers, Amazon RDS for MySQL, and Amazon Aurora, into Azure Database for MySQL flexible server. It supports migrating to MySQL 5.7, 8.0, and 8.4, and from MySQL 5.6 and later to a higher version, including across regions, resource groups, and subscriptions.

The Standard tier is free and supports offline migrations. The Premium tier adds online (continuous) migration and is billed hourly per provisioned vCore, with a 4-vCore Premium instance free for the first six months.
