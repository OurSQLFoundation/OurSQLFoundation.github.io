The MySQL HeatWave Implementation Associate exam (1Z0-915-1) is a dedicated Oracle Certified Associate credential focused specifically on running HeatWave — distinct from the general MySQL Implementation Associate exam, which only tests basic HeatWave awareness. Per Oracle's announcement, it targets data professionals responsible for planning, provisioning, managing, and configuring HeatWave DB systems, including backing up and restoring them, enabling inbound replication and read replicas, and performing data migration into HeatWave.

It's delivered as a proctored, multiple-choice exam through Oracle University, with a Japanese-language version (1Z0-915-1-JPN) also available alongside the English exam.
