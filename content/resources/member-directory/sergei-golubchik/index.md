Sergei Golubchik has been working on the MySQL source code since 1998, and joined MySQL AB as a developer in 2000. He was a primary architect of the MySQL plugin API, co-authored the book *MySQL 5.1 Plugin Development*, and served as MySQL's security coordinator, a role he continues for MariaDB. Since the founding of [MariaDB](/resources/software/mariadb-server/) he has been one of its core architects, and today he is Chief Architect of MariaDB Server at MariaDB plc. He also sits on the board of the MariaDB Foundation.
