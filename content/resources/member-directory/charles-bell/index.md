Charles Bell is a software engineer on the Oracle MySQL development team, where he has led work on MySQL Utilities and on backup and replication. He is the author of *Expert MySQL*, a guide to extending and modifying the MySQL server source code, of [*Introducing MySQL Shell*](/resources/books/introducing-mysql-shell/), and of *MySQL Database Service Revealed* (2022), on running MySQL in Oracle Cloud Infrastructure. With Mats Kindahl and Lars Thalmann he co-authored [*MySQL High Availability*](/resources/books/mysql-high-availability-2nd/), and he has also written several books on MicroPython and embedded systems.
