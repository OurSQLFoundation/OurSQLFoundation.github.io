Marcelo Altmann is a Senior Software Engineer at [Readyset](/resources/software/readyset/), a transparent SQL caching layer for MySQL and PostgreSQL. He has almost 20 years of experience with MySQL and has contributed code fixes to MySQL itself. As a C++ and Rust developer, he builds tools that make databases faster and more reliable, with a focus on performance tuning and MySQL internals. He is part of the Oracle ACE program and a regular speaker at MySQL conferences and events, including Percona Live 2026 in Amsterdam. He speaks at an OurSQL Foundation webinar on November 18, 2026: [What Happened to the MySQL Query Cache?](/community/webinars/mysql-query-cache/)
