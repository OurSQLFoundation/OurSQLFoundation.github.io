Marcelo Altmann is a Senior Software Engineer at [Readyset](/resources/software/readyset/), a transparent SQL caching layer for MySQL and PostgreSQL. He has almost 20 years of experience with MySQL and has contributed code fixes to MySQL itself. As a C++ and Rust developer, he builds tools that make databases faster and more reliable, with a focus on performance tuning and MySQL internals. He is part of the Oracle ACE program.
