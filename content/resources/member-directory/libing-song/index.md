Libing Song contributes to MySQL Server from Alibaba. He has proposed changes to improve [binary log commit performance](https://github.com/mysql/mysql-community/issues/114) and to [roll back prepared transactions asynchronously during crash recovery](https://github.com/mysql/mysql-community/issues/100). AWS also acknowledged his contributions to the collaboration that brought its large-transaction binary log optimization to upstream MySQL. [AWS Database Blog](https://aws.amazon.com/blogs/database/aws-contributes-a-large-transaction-binary-log-optimization-to-mysql/)
