Simon J Mudd is a senior SRE and database expert with more than 15 years of experience, based in Madrid. He is the author of [ps-top](/resources/software/ps-top/), a top-like terminal monitor for MySQL built on `performance_schema`, which he started as a project to learn Go. His other open source work includes grchecker, a monitor for MySQL Group Replication clusters, and a Go library for reading MySQL defaults files. He also presents at community events — for example, a talk at a Madrid MySQL meetup on how Booking.com uses MySQL.
