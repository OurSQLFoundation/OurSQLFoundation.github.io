Jeremy Cole is a database engineer best known for his deep work on InnoDB internals. He created innodb_ruby, a library and toolset for reading InnoDB's on-disk structures, together with Davi Arnaut, and his blog series on InnoDB's file formats is a standard reference on the subject. He has run and developed MySQL at scale at Twitter, Google, and Shopify.
