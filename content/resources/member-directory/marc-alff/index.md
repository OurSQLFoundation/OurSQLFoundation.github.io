Marc Alff began developing MySQL Performance Schema in 2008. It shipped in MySQL 5.5 and gives users visibility into server activity for performance diagnosis. Alff also documented the addition of indexes to Performance Schema tables in MySQL 8.0. [Performance Schema history](https://www.percona.com/sites/default/files/UC2011-Using-MySQL-5.5-Performance-Schema.pdf) · [MySQL engineering blog](https://dev.mysql.com/blog-archive/mysql-8-0-performance-schema-now-with-indexes/)
