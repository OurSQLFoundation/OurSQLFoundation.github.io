Jonathan Desrosiers is a WordPress Core Committer. Part of that work is making sure upcoming WordPress releases support a wide range of MySQL versions; WordPress currently supports MySQL 5.5.5 and later. He first used MySQL in college in the mid-2000s, building custom websites by hand, and soon after discovered WordPress and began digging into its database structure. He attended the community-organized EU Summit for the MySQL Community that followed FOSDEM 2026.
