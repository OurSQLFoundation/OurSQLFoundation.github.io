MySQL Connector/C++ is the official C++ interface for communicating with MySQL servers, developed by the MySQL team at Oracle. It implements the X DevAPI, so applications can connect over `mysqlx://` URLs, and it installs from pre-compiled packages on the MySQL downloads page or builds from source.

It follows the same release numbering as MySQL Server, and the GitHub repository mirrors the source of the latest released version. The community edition is released under GPLv2.
