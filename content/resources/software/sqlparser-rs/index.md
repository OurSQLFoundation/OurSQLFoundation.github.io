sqlparser-rs parses SQL into an abstract syntax tree for Rust programs, and it's used by query engines and SQL tooling across the Rust ecosystem. A MySQL dialect handles MySQL-specific syntax.

It's an Apache Software Foundation project released under the Apache 2.0 license.
