Jet generates Go types from a live database schema and lets you write type-safe SQL against them, mapping results into Go structs. It supports PostgreSQL, MySQL, and SQLite, and MariaDB is tested and known to work. Code generation for MySQL runs with `jet -source=mysql`.

It's released under the Apache 2.0 license.
