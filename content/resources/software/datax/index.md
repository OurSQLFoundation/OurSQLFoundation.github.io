DataX models every data source as a reader plugin and a writer plugin, then moves data between any supported pair in batch. MySQL has both a reader and a writer, alongside many other relational, NoSQL, and big data systems. It's widely used inside Alibaba Group, and its documentation is primarily in Chinese.

It's released under the Apache 2.0 license. The last tagged release is from 2023, though the repository received commits in 2026.
