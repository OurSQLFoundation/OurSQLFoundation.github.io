GraphJin compiles GraphQL into database queries and runs as a Go library, an API service, a REST gateway, or a real-time subscription server. It also exposes a governed graph to AI agents through MCP tools, with query allow-lists and read-only boundaries. MySQL is among its supported databases.

It's released under the Apache 2.0 license.
