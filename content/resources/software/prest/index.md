pREST serves instant REST and MCP APIs on an existing or new database, covering CRUD and custom SQL. PostgreSQL is the default engine, and MySQL 8.0.19 and later has been a separate native dialect since version 2.5.0, with read-only MCP for MySQL since 2.5.1.

It's written in Go and released under the MIT license.
