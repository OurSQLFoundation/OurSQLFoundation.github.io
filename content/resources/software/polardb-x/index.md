PolarDB-X was created to solve the scalability bottleneck of Alibaba Tmall's Double Eleven core transaction system. Its compatibility goal covers the MySQL protocol, most MySQL SQL syntax, collations, transaction isolation levels, and the binary log, and its CDC node works with the MySQL binary log format and dump protocol.

The SQL engine is released under the Apache 2.0 license.
