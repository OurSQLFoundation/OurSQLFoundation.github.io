DataZen is a Tauri/Rust desktop app covering the everyday database workflow: a schema-aware SQL editor with completion, linting, and streaming results; a schema browser with ER diagrams; chart building (line, bar, pie, scatter, area) with PNG/SVG export; and migration tooling including schema diff, data sync, data transfer, and backup.

For MySQL and MariaDB specifically, it offers the full query/schema/EXPLAIN toolset, alongside optional AI features — natural-language-to-SQL, error diagnosis, and EXPLAIN analysis — that can run through OpenAI, Anthropic, DeepSeek, or a local Ollama instance. It can also act as both an MCP server and client.

It ships as native builds for macOS, Windows, and Linux, requires no account, and is released under the GPL-3.0 license (with a linking exception for independently built drivers, themes, and extensions).
