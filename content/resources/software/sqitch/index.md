Sqitch manages schema changes as scripts written in the database's own SQL rather than through an ORM or a DSL, so it fits projects in any language. It supports MySQL 5.1 and later and MariaDB 10.0 and later, alongside engines such as PostgreSQL, SQLite, Yugabyte, and Firebird.

It's written in Perl and released under the MIT license.
