drawDB builds entity-relationship diagrams in the browser with a few clicks, then exports and imports SQL scripts for the chosen database, including MySQL and MariaDB. It runs as a hosted app at drawdb.app and can also be run locally from source.

It's written in JavaScript and released under the AGPLv3.
