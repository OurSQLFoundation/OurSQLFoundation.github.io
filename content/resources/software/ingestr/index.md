ingestr moves data from a source to a destination using command-line flags, with no code, and supports incremental loading strategies such as `append`, `merge`, and `delete+insert`. MySQL is among its supported sources.

It's source-available under the Functional Source License 1.1, which converts to Apache 2.0 over time.
