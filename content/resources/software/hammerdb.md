HammerDB is the industry-standard open-source benchmark for relational databases, generating TPC-C (OLTP) and TPC-H (analytics) style workloads so teams can compare performance across database engines and configurations under identical, repeatable load. Beyond MySQL and MariaDB it also drives Oracle, SQL Server, Db2, and PostgreSQL, which makes it a common choice when validating a migration or benchmarking one engine against another.

It ships a GUI, a CLI, and a web interface, plus official Docker images and CI pipeline integration, so the same workload definitions can run interactively during tuning work or unattended as part of a release pipeline. Results come with automated reporting — metrics, charts, and shareable artifacts — through the TPC community's standard workflow.
