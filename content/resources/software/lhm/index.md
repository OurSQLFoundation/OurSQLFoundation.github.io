Large Hadron Migrator (LHM) changes the schema of large MySQL tables online, for applications where a plain Rails-style migration would lock a table for too long. It works only with MySQL.

This fork is maintained by Shopify, based on the original SoundCloud project, and released under the 3-clause BSD license.
