DBeaver Community gives developers and DBAs a single desktop client for browsing schemas, editing data in a spreadsheet-like grid, writing SQL with autocompletion, building ER diagrams, and importing or exporting data, connecting to MySQL and MariaDB (and most other SQL and NoSQL databases) over JDBC. It runs on Windows, macOS, and Linux as an Eclipse-based Java application.

The Community Edition is fully open source under the Apache 2.0 license; DBeaver also sells a separate commercial "DBeaver PRO" edition built on the same core with added enterprise features and support.
