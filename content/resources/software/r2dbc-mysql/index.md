r2dbc-mysql implements the Reactive Relational Database Connectivity SPI for MySQL. It's meant as the backing implementation for a client library rather than for direct use, and it supports Spring Boot 4.0 and Spring Framework 7 starting from version 1.4.2.

It's released under the Apache 2.0 license.
