Navicat for MySQL is PremiumSoft's dedicated database GUI for MySQL and MariaDB, letting users browse and edit data and schema, build and run SQL with a visual query builder, design ER diagrams, and automate backups and scheduled tasks — all from a single tool that can connect to MySQL and MariaDB servers simultaneously.

It ships for Windows, macOS, and Linux, is sold under a perpetual license or subscription with a free 14-day trial, and sits alongside Navicat's cross-database "Premium" and "Premium Lite" editions in the vendor's product line.
