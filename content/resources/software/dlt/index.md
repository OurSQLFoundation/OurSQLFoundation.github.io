dlt (data load tool) is a library rather than a platform, so it can be dropped into a notebook, a serverless function, an Airflow DAG, or a laptop. Its `sql_database` source reads from MySQL with a standard connection string such as `mysql+pymysql://`.

The library is released under the Apache 2.0 license. dltHub, launched in March 2026, is a separate managed commercial platform built around it.
