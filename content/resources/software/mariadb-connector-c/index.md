MariaDB Connector/C is the foundational native driver for talking to MariaDB and MySQL servers from C or C++, implementing the wire protocol, authentication plugins, and connection pooling that sit underneath it. Several of MariaDB's own higher-level connectors (and some third-party drivers in other languages) link against it rather than re-implementing the protocol themselves.

It's released under the LGPL 2.1, developed in the `mariadb-corporation` GitHub organization, and is currently at version 3.4.11 with more than 2,500 commits on its active branch.
