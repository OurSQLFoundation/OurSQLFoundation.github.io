Beekeeper Studio gives developers and DBAs a tabbed SQL editor with autocomplete and syntax highlighting, an Excel-like data grid for browsing and editing table rows, query history, and CSV/JSON import and export, aimed at staying fast and simple rather than feature-heavy. It grew out of the Sqlectron-core project and ships prebuilt binaries for Windows, macOS, and Linux.

MySQL and MariaDB have full support in both the free Community edition and the paid Ultimate edition. The Community edition's code is open source under the GPLv3 license and free to use with no sign-up required; Ultimate adds features such as cloud connection sync and additional database drivers under a separate commercial, source-available license.
