Harlequin brings a full SQL IDE to the terminal, so it works over SSH and alongside other command-line tools. MySQL support comes through an adapter installed as an extra, for example `uv tool install 'harlequin[postgres,mysql,s3]'`.

It's written in Python and released under the MIT license.
