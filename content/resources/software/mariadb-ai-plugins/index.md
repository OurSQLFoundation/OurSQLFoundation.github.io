MariaDB AI Plugins give coding agents two things: skills with reference material on topics such as `ALTER TABLE` behavior, vector indexes, connector choice, and moving an application from MySQL, plus a live MCP connection through `mariadb-shell` that can read schemas, run queries, and analyze slow queries with `EXPLAIN`.

This repository replaced the earlier `MariaDB/mcp` project, deprecated in November 2026. The plugins are released under GPLv2, and bundled skills keep the licenses of their source repositories.
