ocelotgui connects to MySQL or MariaDB servers to run SQL statements, with syntax highlighting, user-settable colors and fonts, result sets with multi-line rows and resizable columns, and a debugger. It needs the `libmysqlclient` library at runtime.

It's written by Peter Gulutzan and released under GPLv2. Its latest release, 2.6.0, is from October 2025.
