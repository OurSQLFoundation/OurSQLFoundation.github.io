RonDB is a distribution of NDB Cluster, the distributed storage engine behind MySQL Cluster, packaged and maintained by the RonDB team at Hopsworks. It's based on a MySQL release, so it keeps MySQL's SQL interface on top of NDB's in-memory, shared-nothing storage.

Its source is published on GitHub alongside MySQL Community licensing information.
