SqlSugar is an ORM for .NET Framework and modern .NET maintained by the Fructose Big Data Technology team. Its database list includes MySQL, MariaDB, TiDB, Percona Server, Amazon Aurora, and Azure Database for MySQL, as well as SQL Server, PostgreSQL, Oracle, and many Chinese databases.

It's released under the MIT license.
