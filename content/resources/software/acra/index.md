Acra provides application-level encryption for data fields, multi-layered access control, database leakage prevention, and intrusion detection in one suite, working as a proxy between applications and the database. It supports MySQL 5.7 and later, MariaDB 10.3, and PostgreSQL, including on Google Cloud SQL and Amazon RDS.

Acra Community Edition is released under the Apache 2.0 license, and Cossack Labs offers commercial editions.
