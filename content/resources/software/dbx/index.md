DBX is a desktop (Windows/macOS/Linux), Docker, and CLI database client built in Rust, packaged at around 25 MB with no bundled Chromium. It connects natively to MySQL, MariaDB, PostgreSQL, SQLite, MongoDB, Redis, ClickHouse, SQL Server, Oracle, TiDB, OceanBase, Doris, StarRocks, Dolt, and dozens more, with additional databases reachable through agent-based and JDBC-driven profiles. Each connection gets a built-in AI assistant for generating and explaining SQL, and the client ships its own MCP server so AI coding tools can query a connected database directly.

The project is free and open source under the Apache 2.0 license, with a plugin system (`t8y2/dbx-store`) for community-contributed extensions. It has attracted a fast-growing GitHub community and was featured on Product Hunt and HelloGitHub.
