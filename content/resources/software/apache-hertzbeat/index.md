Apache HertzBeat monitors applications, databases, and infrastructure from a single system, and MySQL is among the monitoring types defined in its main repository. It can also store its own data in MySQL or PostgreSQL, and a docker-compose script installs it together with its dependencies.

It's written in Java and released under the Apache 2.0 license.
