ShannonBase aims to replace a stack of ETL pipelines, vector databases, and inference servers with one database, letting you train ML models, run LLMs, search vectors, and build RAG pipelines in SQL. It's wire-protocol compatible with MySQL, so existing drivers, ORMs, and tools keep working.

It's released under GPLv2, consistent with MySQL Community Server.
