Heimdall's proxy sits in front of the database, so applications only change the host and port they connect to. For MySQL it adds automated query caching and invalidation, read/write splitting that accounts for replication lag and transaction state, connection pooling, and automated failover, and it's documented for Amazon RDS, Aurora, and Azure Database for MySQL. The company also offers a database PAM product.

It's a commercial product, with a free trial.
