ClickHouse generates analytical reports in real time from a column-oriented store. It connects to the MySQL world in two directions: a MySQL table engine reads from a remote MySQL server, and a built-in MySQL protocol handler lets MySQL clients connect to ClickHouse.

It's released under the Apache 2.0 license, and ClickHouse, Inc. offers a commercial cloud service.
