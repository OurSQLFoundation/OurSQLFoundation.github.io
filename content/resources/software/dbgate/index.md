DbGate is a database manager built to work with several databases at once, adding schema comparison, a visual query designer, chart visualization, and batch data import/export on top of the usual table browsing and SQL editing. Beyond MySQL and MariaDB it connects to PostgreSQL, SQL Server, Oracle, MongoDB, Redis, SQLite, ClickHouse, Cassandra, DuckDB, Firebird, and more.

It runs as a desktop app for Windows, Linux, and macOS, as a Docker container, or as a web application via the `dbgate-serve` npm package — a hosted demo is available at demo.dbgate.org. The core is licensed under GPL-3.0 and free for any purpose; a separate DbGate Premium license unlocks a handful of additional connectors (Amazon Redshift, CosmosDB, libSQL/Turso, Firestore).
