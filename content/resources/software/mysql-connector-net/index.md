MySQL Connector/NET gives applications written in .NET languages access to MySQL through a fully managed ADO.NET driver, and it works with both .NET Framework and modern .NET. Beyond the classic data provider it includes an X DevAPI implementation, Entity Framework Core support, OpenTelemetry tracing, WebAuthn authentication, and TLS 1.3.

It's developed by the MySQL team at Oracle and follows the same release numbering as MySQL Server. The community edition is released under GPLv2. It's a separate project from the community-maintained [MySqlConnector](/resources/software/mysqlconnector-dotnet/) driver.
