Zabbix monitors the performance and availability of network devices, servers, services, and other IT resources, using agent-based or agentless collection, automatic discovery, and problem detection with root cause analysis. MySQL monitoring comes through templates shipped in the main repository, so database health can sit in the same system as the rest of the infrastructure.

It's released under the AGPLv3.
