ILLA Builder provides components and actions for assembling internal tools, with real-time collaboration and automation. It connects to MySQL and REST APIs through GUI data connectors, and it can be self-hosted with Docker or Kubernetes or used through ILLA Cloud.

It's released under the Apache 2.0 license. Its latest tagged release is from August 2024, though the repository received commits in November 2026.
