MariaDB Connector/Python lets Python programs access MariaDB and MySQL through an API compliant with the Python DB API 2.0 (PEP 249). It's written in C and uses the [MariaDB Connector/C](/resources/software/mariadb-connector-c/) client library for client-server communication, unlike pure-Python drivers such as [PyMySQL](/resources/software/pymysql/).

It's maintained in the `mariadb-corporation` GitHub organization and released under the LGPL 2.1 or later.
