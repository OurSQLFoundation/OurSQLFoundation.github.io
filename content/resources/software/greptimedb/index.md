GreptimeDB stores metrics, logs, and traces in one engine and answers queries in SQL and PromQL. It exposes a MySQL protocol endpoint, so MySQL clients can connect and run SQL against observability data.

It's written in Rust. GreptimeDB is open core: the core is released under the Apache 2.0 license, and a small set of enterprise-only features is gated separately.
