innodb_ruby reads InnoDB's on-disk structures directly, which makes it useful for learning how pages, records, and indexes are laid out and for demonstrating those structures interactively from `irb`. Its README is explicit that it's a learning and teaching tool rather than something for critical production use.

It's written by Jeremy Cole, distributed as a Ruby gem, and released under the 3-clause BSD license.
