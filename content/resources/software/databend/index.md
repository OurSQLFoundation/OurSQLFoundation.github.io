Databend runs analytics on object storage and adds vector and full-text search in the same engine. It includes a MySQL protocol handler, so standard MySQL clients and tools can connect to it.

The core is released under the Apache 2.0 license, and a small set of enterprise features is under the Elastic License 2.0. Databend also runs as a hosted cloud service.
