CloudBeaver brings database management to the browser: a Java web server with a TypeScript and React interface that a team can host once and open from anywhere, instead of installing the [DBeaver](/resources/software/dbeaver/) desktop client on each machine. It's distributed as an official Docker image, with deployment instructions in the project wiki.

The Community Edition is free and released under the Apache 2.0 license, and the DBeaver team also sells commercial editions.
