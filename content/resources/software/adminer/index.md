Adminer packages browsing, editing, and administering a database — running queries, managing users and permissions, exporting and importing data — into one dependency-free PHP file you copy to a server and open in a browser. It supports MySQL, MariaDB, PostgreSQL, SQLite, MS SQL, Oracle, and Elasticsearch/MongoDB through plugins, and ships with dozens of community-contributed design themes.

The project is dual-licensed under the Apache License 2.0 and GPL v2, and is developed in the open on GitHub. A companion project, Adminer Editor, offers a stripped-down interface aimed at letting non-technical end users edit data without exposing the rest of the schema.
