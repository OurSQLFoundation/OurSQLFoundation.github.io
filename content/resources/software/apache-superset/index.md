Apache Superset connects to MySQL and many other SQL-speaking databases, then lets people build charts without code, write queries in its SQL editor, and assemble the results into interactive dashboards. Because it queries the database directly, it doesn't need a separate ingestion layer.

Superset is a top-level Apache Software Foundation project, written mainly in Python and released under the Apache 2.0 license.
