JumpServer gives DevOps and IT teams one place for audited access to SSH, RDP, Kubernetes, databases, and web applications. The open-source edition includes a web database connector and can rotate MySQL account passwords, while a database protocol proxy is part of the Enterprise Edition.

It's released under GPLv3.
