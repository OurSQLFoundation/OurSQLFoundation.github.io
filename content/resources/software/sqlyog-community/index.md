SQLyog is a long-standing GUI for managing MySQL and MariaDB in physical, virtual, and cloud environments. It runs on Microsoft Windows and may also run on Linux and Unix through Wine, and it has no dependencies on runtimes such as .NET and Java or on abstraction layers such as ODBC and JDBC.

The Community Edition is released under GPLv2, with support through Webyog's forums. Webyog also sells commercial editions.
