LINQ to DB lets .NET code query databases with LINQ expressions rather than SQL strings, while staying a thin layer without change tracking. It sits one step above micro-ORMs like Dapper and is lighter than Entity Framework. A MySQL data provider is included.

It's released under the MIT license.
