The Mysql2 gem deliberately avoids a 1:1 mapping of the C API. It focuses on connecting, querying, and iterating on results, forces UTF-8 or binary for the connection, and uses encoding-aware MySQL API calls where it can.

It's released under the MIT license. It's a separate project from the Node.js [mysql2](/resources/software/mysql2/) driver.
