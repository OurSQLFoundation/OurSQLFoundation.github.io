SQL Studio starts a local web UI for exploring a database from one command, such as `sql-studio mysql [url]` for a MySQL or MariaDB server. It also supports SQLite, libSQL, PostgreSQL, DuckDB, ClickHouse, Microsoft SQL Server, Parquet, and CSV.

It's written in Rust and released under the MIT license.
