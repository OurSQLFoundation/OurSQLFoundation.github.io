SQL Diagnostic Manager for MySQL, originally Webyog's Monyog, monitors MySQL and MariaDB performance and configuration in real time with smart alerts. It also covers managed cloud databases such as Amazon RDS and Aurora, Azure Database for MySQL, and Google Cloud SQL.

It's a commercial product from IDERA, with a free trial.
