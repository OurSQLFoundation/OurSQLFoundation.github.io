MatrixOne combines transactional and analytical workloads with vector search in one engine, and adds Git-style versioning so data can be branched and compared like code. It's designed as a drop-in replacement for MySQL, so existing tools, ORMs, and applications can connect without code changes.

It's developed by MatrixOrigin, written in Go, and released under the Apache 2.0 license.
