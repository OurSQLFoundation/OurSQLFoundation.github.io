Aqua Data Studio combines SQL development, data modeling, visual analytics, and database administration across more than 40 data sources on Windows, macOS, and Linux. For MySQL and MariaDB it includes DBA tools such as instance, storage, security, and session managers.

It's a commercial product from IDERA, sold in Standard and Ultimate editions.
