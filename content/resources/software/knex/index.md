Knex.js is a "batteries included" SQL query builder for Node.js, offering a chainable API for building SELECT, INSERT, UPDATE, and DELETE queries, a schema builder for creating and altering tables, and a migration and seed system for versioning a database's structure and seed data. It connects to MySQL through the `mysql` or `mysql2` driver, and ships dedicated query compilers for PostgreSQL, SQL Server, SQLite3, Redshift, CockroachDB, and Oracle alongside its MySQL support.

Originally created by Tim Griesser in 2013, it's released under the MIT license, has around 20k stars on GitHub, and underpins higher-level tools such as the Objection.js ORM.
