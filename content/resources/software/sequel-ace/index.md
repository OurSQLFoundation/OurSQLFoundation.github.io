Sequel Ace is a fast, native macOS application for connecting to and managing MySQL (5.7+) and MariaDB (10.0+) databases, continuing the work of the discontinued Sequel Pro and CocoaMySQL projects. It runs on both Intel and Apple Silicon Macs and includes an optional, off-by-default MCP server that lets AI agents such as Claude Code query databases through Sequel Ace's existing connections in read-only mode.

It's free and open source under the MIT license, maintained by Moballo, LLC, and installable from the Mac App Store or via Homebrew Cask.
