Percona Database Service lets platform engineers create, connect, scale, back up, restore, monitor, and delete databases from one UI, and open Percona support cases from the same place, while the data stays in their own clusters and backup buckets. It provisions MySQL as Percona XtraDB Cluster and PostgreSQL through the Percona Operator for PostgreSQL, and it builds on [OpenEverest](/resources/software/openeverest/).

PDS is in alpha with no backward compatibility yet, and it's released under the Apache 2.0 license.
