MariaDB Connector/Node.js is a 100% JavaScript client for MariaDB and MySQL with TypeScript definitions. Its main API is Promise-based, and a callback wrapper is available for code that expects the interface of the older `mysql` and `mysql2` packages, with a migration guide in the documentation.

It's maintained in the `mariadb-corporation` GitHub organization and released under the LGPL 2.1 or later. Since version 3.5.3 it requires Node.js 20 or later.
