test_db is the Employees sample database referenced in the MySQL documentation, with a test suite that verifies the data loaded correctly. It requires MySQL 5.0 or later or PostgreSQL 12 or later, and it's tested in CI against MySQL versions up to 9.6 and MariaDB 10.11, 11.4, and 12.1.
