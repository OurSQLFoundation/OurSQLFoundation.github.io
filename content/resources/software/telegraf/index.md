Telegraf collects metrics, logs, and other data through a plugin architecture and writes them to InfluxDB and many other outputs. Its MySQL input plugin gathers statistics from MySQL server instances, including Performance Schema metrics once that schema is enabled.

It's written in Go and released under the MIT license.
