MySQL Connector/ODBC is the official ODBC driver for MySQL, the route for any application or reporting tool that talks to databases through the ODBC API instead of a language-specific driver. It installs from pre-compiled packages on the MySQL downloads page, with source packages published on GitHub.

It's developed by the MySQL team at Oracle and follows the same release numbering as MySQL Server. The community edition is released under GPLv2.
