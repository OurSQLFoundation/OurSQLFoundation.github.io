Antares aims to be a useful SQL client for developers on all major operating systems, including ARM builds. It currently supports MySQL and MariaDB, PostgreSQL, SQLite, and Firebird SQL, and its README describes it as still in development.

It's released under the MIT license. Its latest tagged release is from June 2025, though the repository received commits in November 2026.
