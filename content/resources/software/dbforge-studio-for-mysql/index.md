dbForge Studio for MySQL covers the database lifecycle for MySQL, MariaDB, Amazon RDS, Aurora, and other cloud services, with tools such as a query profiler with execution plans, a data generator, database design, and source control. Higher editions add a MySQL debugger and backup and recovery tools.

It's a commercial product sold by subscription in several editions, with a 30-day free trial.
