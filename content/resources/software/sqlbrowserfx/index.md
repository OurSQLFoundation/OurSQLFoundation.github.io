SqlBrowserFX combines a syntax-highlighted SQL/Java editor, a hierarchical database tree view, CSV import/export, query history, and savable queries with an ERD diagram generator for visualizing schema relationships. A built-in feature can expose any connected database as a RESTful web service with one click, and the client can optionally connect to a local Ollama installation to add AI query assistance.

It's a Java/Maven project built on JavaFX (with DockFX, RichTextFX, ControlsFX, and the Javalin web framework), distributed as a standalone app or fat JAR for Windows, Linux, and macOS, and released under the MIT license.
