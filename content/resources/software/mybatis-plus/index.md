MyBatis-Plus builds on [MyBatis](/resources/software/mybatis/) with out-of-the-box features such as code generation, conditional query builders, and pagination plugins, including a MySQL pagination dialect. Its documentation is primarily in Chinese.

It's released under the Apache 2.0 license.
