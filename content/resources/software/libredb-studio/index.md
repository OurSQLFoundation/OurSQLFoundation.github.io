LibreDB Studio puts many database engines behind a single browser tab, including MySQL, PostgreSQL, Oracle, SQL Server, SQLite, DuckDB, MongoDB, Redis, and ClickHouse. Rather than running on each person's machine, it's deployed close to the data it manages.

It's written in TypeScript and released under the MIT license.
