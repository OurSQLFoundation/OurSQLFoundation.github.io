MySQL Connector/J is the official pure-Java driver that lets any JDBC-based application — application servers, connection pools, ORMs like Hibernate — talk to MySQL without a native client library. Alongside classic JDBC, it implements the MySQL X DevAPI, giving Java code a document-style CRUD interface over the X Protocol as an alternative to writing SQL directly.

It's released under GPLv2 with a FOSS exception (the same dual-licensing model Oracle uses across the MySQL product line), developed in the `mysql` GitHub organization, and is currently at version 26.7.0 after more than 3,200 commits.
