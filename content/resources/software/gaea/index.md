Gaea is Xiaomi's in-house middleware for MySQL, sitting between applications and multiple database clusters. Its feature list covers multi-tenancy, read/write splitting with replica load balancing, SQL interception and filtering, and slow and error SQL fingerprints. Its documentation is primarily in Chinese.

It's written in Go and released under the Apache 2.0 license.
