Peewee is a single module with no required dependencies that has run production workloads since 2010. It pairs a small set of ORM concepts with a flexible query builder, and its MySQL support installs with `pip install peewee[mysql]` (PyMySQL) or `peewee[aiomysql]` for asyncio.

It's released under the MIT license.
