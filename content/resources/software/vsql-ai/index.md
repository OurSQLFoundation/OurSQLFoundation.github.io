vsql-ai adds functions to [VillageSQL](/resources/software/villagesql/) for prompting AI models from SQL queries and for creating text embeddings for vector search, using Anthropic Claude, Google Gemini, OpenAI, or local Ollama models over HTTPS.

It's an early-stage extension written in C++ and released under GPLv2.
