StackRender takes a schema from specification to a working database design through an interactive diagram editor, then exports it in your preferred SQL dialect: MySQL, MariaDB, PostgreSQL, SQLite, Oracle, or SQL Server.

It's written in TypeScript and released under the AGPLv3.
