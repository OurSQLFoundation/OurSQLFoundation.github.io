mycli is a terminal client for MySQL-family databases built on Python's `prompt_toolkit`, offering context-aware auto-completion for keywords, tables, views, and columns, plus syntax highlighting via Pygments as you type. It adds conveniences a plain `mysql` CLI session doesn't have: fuzzy history search, saved favorite queries with Jinja-templated parameters, many tabular output formats, and credentials stored in the system keyring instead of plain config files.

It's maintained by the `dbcli` project — the same team behind `pgcli` for PostgreSQL — and is released under the BSD-3-Clause license.
