MariaDB4j packages native MariaDB binaries for Windows, Linux, and macOS in Maven JARs and starts them from Java. It can be used through its `DB` API, with Spring, from JUnit tests, as a Maven plugin, or from a CLI, which makes it a convenient way to run a real database in integration tests.

It's released under the Apache 2.0 license.
