The `devsec.hardening` collection applies security hardening through Ansible, including a `mysql_hardening` role for MariaDB and MySQL servers. Its README lists support for MySQL 5.7.31 and 8.0.3 or later and for several MariaDB versions.

It's released under the Apache 2.0 license.
