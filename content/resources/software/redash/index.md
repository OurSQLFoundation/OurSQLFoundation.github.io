Redash lets anyone write SQL against a connected data source — MySQL is one of more than 35 built-in supported sources, alongside PostgreSQL, Amazon Redshift, Google BigQuery, and others — then turn the result into a chart or combine several into a shareable dashboard, without needing to master separate BI software. Dashboards and individual queries can be scheduled to refresh automatically, shared by URL, and set up with alerts that fire when a query's result crosses a defined condition.

The project is released under the BSD 2-Clause license and is self-hosted, typically deployed via Docker. It's maintained on GitHub at `getredash/redash` under calendar-style versioning (e.g. `26.10.x` for the October 2026 release line), with an active CI pipeline and ongoing commits as of this writing.
