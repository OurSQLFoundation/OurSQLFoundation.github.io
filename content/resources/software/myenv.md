FromDual MyEnv is a database environment to run and operate several different MySQL and MariaDB (as well as PostgreSQL) instances simultaneously on the SAME machine. You can even run multiple database instances with different binary versions. We call this multi-instance set-ups.

Today you probably would do this with virtual machines or containers...
