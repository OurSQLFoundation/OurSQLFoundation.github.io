TablePro is a database client built natively in Swift/SwiftUI rather than on Electron, JDBC, or a JavaScript runtime, aimed at staying fast and lightweight. It covers an SQL editor with autocomplete, multi-cursor editing, Vim mode, and syntax themes; an inline-editable data grid with sorting, filtering, and undo/redo; native window tabs and split panes; SSH tunnels and SSL/TLS; searchable query history; and built-in AI chat, inline suggestions, and Explain/Optimize, plus an MCP server and URL scheme for tools like Raycast, Cursor, and Claude Desktop. MySQL support ships as one of its built-in or on-demand plugin drivers.

Every feature above is free on every database, with no trial period. Optional paid Starter and Team licenses add Mac-only extras — iCloud Sync, encrypted export, environment variables, linked folders, query insights, result charts, Compare & Sync, and Data Rewind, plus (Team) a shared catalog and library; the iPhone/iPad app needs no license. It runs on macOS 13+ and iOS/iPadOS 18+ today, with a Linux build in development, and is released under the AGPL-3.0 license (the TablePro name and icon are excluded and governed separately).
