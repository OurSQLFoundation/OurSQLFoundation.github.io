Squix is a terminal UI for working with SQL databases without leaving the keyboard, built in Go on top of the BubbleTea TUI framework. It covers the usual DBA/developer workflow in a single interactive shell: browsing schemas, running ad hoc queries, viewing and editing table data in place cell-by-cell or row-by-row, and exporting results to CSV, JSON, SQL, Markdown, or HTML. A saved query library and quick connection switching let it double as a lightweight SQL notebook across multiple databases.

Alongside MySQL and MariaDB, it also connects to PostgreSQL, SQL Server, Oracle, SQLite, ClickHouse, Firebird, and DuckDB through the same interface. It's released under the MIT license and has a small but active community, including a public Matrix chat room for support and discussion.
