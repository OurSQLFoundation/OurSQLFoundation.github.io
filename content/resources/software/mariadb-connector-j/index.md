MariaDB Connector/J is the official JDBC driver maintained by MariaDB Corporation for connecting Java applications to both MariaDB and MySQL servers. It ships as two supported lines — a 3.5.x branch for Java 8 and a 4.x branch for Java 17+ — and is used as the underlying driver by higher-level frameworks and tools that need JDBC access to MariaDB/MySQL.

It's released under the LGPL 2.1 (or later), developed in the `mariadb-corporation` GitHub organization, with the latest release (3.5.10) published in July 2026.
