PHPRunner is Xlinesoft's low-code application builder: point it at an existing database, and it generates a web application with list, add, edit, view, search, export, and print pages, reports, charts, dashboards, authentication, and user and group permissions. Pages are designed visually, and behavior can be extended with events and custom code. Typical projects are internal database applications, administrative interfaces, and customer or partner portals.

It works with MySQL and MariaDB, as well as SQL Server, PostgreSQL, Oracle, Microsoft Access, IBM DB2, Informix, SQLite, and ODBC-compatible databases. The development application runs on Windows, macOS, and Linux, and the resulting application is used in a browser and deployed on the customer's own web server (Apache or Microsoft IIS with a compatible PHP runtime). PHPRunner is application-building software rather than a database engine or a general-purpose DBA client. It is sold in Professional, Enterprise, and Multi Developer editions with a 21-day trial.
