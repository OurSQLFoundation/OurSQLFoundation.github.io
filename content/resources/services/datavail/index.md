Datavail is a data and technology services company whose work spans remote DBA support, analytics, and application development. Its MySQL practice can supplement an existing team, take on a specific project, or provide complete managed support, with a U.S.-based primary DBA leading each dedicated team.

The MySQL services it lists include database architecture, performance tuning, high availability and clustering, backups, disaster recovery, upgrades and cloud migrations, operations automation, and security audits, for Oracle MySQL, Percona Server, and MariaDB.
