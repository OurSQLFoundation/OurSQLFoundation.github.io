MySQL Public Discussion #6 is a one-hour public Zoom webinar hosted by the MySQL Community Team at Oracle (Lenka Kasparova, MySQL Community Manager & Events Coordinator). This installment focuses on MySQL community engagement and metrics, continuing discussion of community participation, roadmap transparency, GitHub collaboration, and governance, with open Q&A with the MySQL team. Open to any MySQL user, developer, DBA, community organizer, partner, or contributor. Runs 17:00–18:00 UTC (10:00–11:00 PT · 19:00–20:00 CEST).
